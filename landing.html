Everything it offers

One platform: builder, trigger endpoint, queue, executor and live monitor.

Visual flow builder

Drag-free canvas on React Flow with a configurable node sidebar. Wire trigger → action chains.

Webhook triggers

Every flow gets a public /webhook/:path endpoint, signed with HMAC-SHA256.

Built-in actions

HTTP requests with {{ variable }} interpolation from prior steps, plus delay.

Durable execution

BullMQ + Redis queue. The worker runs flows with retries, backoff and step-level input/output/error tracking.

Live monitoring

Execution lifecycle events stream over WebSocket straight to the UI.

Extensible integrations

Integrations register manifests (triggers, actions, JSON config schemas) via @flowforge/integrations.

Encrypted credentials

AES-256-GCM with CREDENTIAL_ENCRYPTION_KEY. Decryption happens only inside the worker.

Safe graph execution

Kahn's topological sort, cycle rejection, reachable nodes run in order.

Docker ready

One docker compose up --build: nginx on :80 proxies /api, /ws, /webhook/.

Quick start

Needs Node ≥ 22, pnpm ≥ 9, Docker Compose.

# install + configure
pnpm install
cp .env.example .env
node -e "console.log(require('crypto').randomBytes(32).toString('hex'))"   # → CREDENTIAL_ENCRYPTION_KEY

# infra + schema
docker compose up -d postgres redis
pnpm --filter @flowforge/db db:push

# api + worker + web, all watching
pnpm dev          # UI → http://localhost:5173 · health → http://localhost:4000/healthz

Production-like: docker compose up --build → UI + API on http://localhost. db-init runs drizzle-kit push before the API starts.

Trigger from anywhere

Each flow has a unique path and secret. Sign the body, POST it.

SECRET=<the flow's secret>
BODY='{"hello":"world"}'
SIG=$(printf '%s' "$BODY" | openssl dgst -sha256 -hmac "$SECRET" -hex | awk '{print $2}')
curl -X POST http://localhost/webhook/<path> \
  -H "Content-Type: application/json" \
  -H "x-flowforge-signature: $SIG" \
  -d "$BODY"
